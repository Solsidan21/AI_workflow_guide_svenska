**Vad det är:** Ett system som håller reda på varje ändring i dina filer. Du kan alltid se vad som ändrats och gå tillbaka till en tidigare version.

**Liknelse:** Spara version i Word, fast för en hel mapp och med en dagbok över varje ändring.

**Varför det spelar roll här:** Git är säkerhetsnätet när en modell får ändra filer åt dig. Går något snett backar du, och du kan prova nya upplägg utan att riskera det som fungerar.
